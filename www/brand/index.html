Brand

The pieces every Greylock Labs app is made from: the logo, the type, and Callie's colors, which you can take into your own terminal, editor and projects.

Logo

Plum, #a64b7a, on its own or on a light page. Give it room, and keep it the one color it is.

Type

Fraunces Headings and the occasional flourish.
Nunito Everything else: soft, round and easy to read small.

Both are under the SIL Open Font License, and ship with the apps.

Colors

Two themes, Callie and Callie Light. Every Greylock Labs app uses them, and their 16 terminal colors sit evenly beside the pink accent. Click a swatch to copy it.

Use the themes

Each port is generated from the same palette in greylocklabs/themes. Most keep a file per variant; pick callie for dark or callie-light for light.

kitty 
curl -fsSLo ~/.config/kitty/callie.conf https://raw.githubusercontent.com/greylocklabs/themes/main/ports/kitty/callie.conf
echo 'include callie.conf' >> ~/.config/kitty/kitty.conf

To follow your desktop's light or dark setting instead, save the two files as dark-theme.auto.conf and light-theme.auto.conf, with no include.

Konsole 
mkdir -p ~/.local/share/konsole
curl -fsSLo ~/.local/share/konsole/Callie.colorscheme https://raw.githubusercontent.com/greylocklabs/themes/main/ports/konsole/Callie.colorscheme
curl -fsSLo ~/.local/share/konsole/CallieLight.colorscheme https://raw.githubusercontent.com/greylocklabs/themes/main/ports/konsole/CallieLight.colorscheme

Then pick Callie under Settings, Edit Current Profile, Appearance.

Ghostty 
mkdir -p ~/.config/ghostty/themes
curl -fsSLo ~/.config/ghostty/themes/Callie https://raw.githubusercontent.com/greylocklabs/themes/main/ports/ghostty/Callie
curl -fsSLo "$HOME/.config/ghostty/themes/Callie Light" "https://raw.githubusercontent.com/greylocklabs/themes/main/ports/ghostty/Callie%20Light"

Then set theme = light:Callie Light,dark:Callie in Ghostty's config.

Alacritty 
curl -fsSLo ~/.config/alacritty/callie.toml https://raw.githubusercontent.com/greylocklabs/themes/main/ports/alacritty/callie.toml

Then add general.import = ["~/.config/alacritty/callie.toml"] to alacritty.toml.

foot 
curl -fsSLo ~/.config/foot/callie.ini https://raw.githubusercontent.com/greylocklabs/themes/main/ports/foot/callie.ini

Then add include=~/.config/foot/callie.ini to foot.ini.

WezTerm 
mkdir -p ~/.config/wezterm/colors
curl -fsSLo ~/.config/wezterm/colors/Callie.toml https://raw.githubusercontent.com/greylocklabs/themes/main/ports/wezterm/Callie.toml

Then set config.color_scheme = "Callie".

Neovim

Install the themes repository as a plugin, here with lazy.nvim:

{
  "greylocklabs/themes",
  name = "callie",
  priority = 1000,
  config = function()
    vim.cmd.colorscheme("callie")
  end,
}

callie follows background, so :set background=light switches to Callie Light. It covers Treesitter, LSP, diagnostics, gitsigns, Telescope, bufferline and more.

opencode 
mkdir -p ~/.config/opencode/themes
curl -fsSLo ~/.config/opencode/themes/callie.json https://raw.githubusercontent.com/greylocklabs/themes/main/ports/opencode/callie.json

Then set "theme": "callie" in tui.json. One file holds both variants, following the terminal.

tuicr 
mkdir -p ~/.config/tuicr/themes
curl -fsSLo ~/.config/tuicr/themes/callie.toml https://raw.githubusercontent.com/greylocklabs/themes/main/ports/tuicr/callie.toml

Then set theme = "callie" in tuicr's config.toml.

lazygit, ghzinga, herdr, Claude Code

These draw with your terminal's colors, so set the terminal theme above, then:

  • lazygit follows it by default.
  • ghzinga and herdr: set the theme to "terminal".
  • Claude Code: run /theme and pick an "ANSI colors only" theme.
The web 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/greylocklabs/themes@main/ports/css/callie.css">

It sets --callie-* variables, light by default and dark when the system prefers it; data-theme="light" or "dark" on the root element chooses one.

body {
  background: var(--callie-bg);
  color: var(--callie-fg);
}
a { color: var(--callie-accent); }

For build scripts and other tools, every color is also in callie.json.
